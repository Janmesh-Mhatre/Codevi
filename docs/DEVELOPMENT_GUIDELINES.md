# Development Guidelines

## General Rules

-   Keep phases independent.
-   Never overwrite working functionality.
-   Use Git commits after every successful phase.
-   Review and test before moving forward.

## Code Standards

-   Clean architecture
-   SOLID principles
-   Reusable components
-   Meaningful names
-   Minimal duplication

## Testing

After every phase: - Build successfully - No runtime errors - Previous
phase still works - New functionality tested
